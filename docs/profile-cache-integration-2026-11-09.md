## 账号存储与兼容性

- `profiles.json` 保存账号名称、不可变 ID 和当前选择；不把密码集中放进索引。
- 原有账号继续使用数据目录原位置的 `identity.json`、`session.json`、`config.json` 等文件；无需搬迁、重新生成 UUID 或重新登录。
- 新账号使用 `accounts/<UUID>/`，各自独立保存身份、会话、配置、点位和 AI 列表缓存。名称不参与路径拼接。
- 2026-11-11 修正：新建时生成独立设备身份，位置初始值沿用当前配置；旧重复环境会备份后修复。见 [独立环境修复说明](profile-independent-environments-2026-11-11.md)。清空账号密码与学校选择，不复制登录会话。
- 每个 UI 回调及后台任务绑定存储目录。切换后，旧线程仍只能写回旧账号，旧消息通道与账号页面状态一起丢弃。
- 登录、成绩提交及程序更新进行中禁止切换；切换不向服务端请求登出。显式登出立即删除当前本地会话；远端登出线程不再写会话文件，防止切回账号时恢复旧会话或晚到响应删除后续登录。
- Unix 下账号目录 0700，索引及凭证文件 0600，沿用版本化状态层和原子写入。
- 支持新增、切换、重命名和移除非当前账号。移除只更新索引，保留本地文件用于恢复；原有账号不允许移除。
- 索引损坏时显示错误并禁用账号管理，不静默覆盖索引。切换失败时保持当前账号。
- CLI 沿用 fork 的兼容策略，继续使用原有账号的数据目录，不随 GUI 当前 profile 切换。

## 表单

桌面改为等宽两列，标签放在输入框上方，操作按钮独占下一行；手机仍纵向排列，并将账号选择与登录状态合并成一行以保留内容区域。增加显示密码开关，账号切换后恢复隐藏。登录输入控件 ID 包含 profile，避免复用另一个账号的编辑状态。

## 路网缓存

- 原有 XML、二进制图和元数据缓存仍保存在共享的 `school_roads/`，不同账号可复用同校同范围的公开地图。
- 为新缓存记录实际 WGS 下载包围框与查询版本。无围栏时，当前点位及预留范围完全被缓存包围框覆盖，才可复用；不会把下载范围当作学校边界。
- 7 天 TTL、学校隔离、查询/解析版本校验与强制刷新继续生效；显示名称和点位更新不改变下载时间或扩大覆盖范围。
- 旧缓存只有在当前查询版本的 key 能证明原始下载输入时，才重建覆盖范围；否则仅按原规则读取。
- 启动/切换至道路模式账号后先恢复同校且覆盖当前位置的底图。账号内的 `road_hint.json` 记录最近使用的缓存；其他同校 profile 可从共享缓存发现底图。
- 过期底图可用于离线显示，后台仍刷新当前账号的学校策略、围栏和点位。失败时保留底图并说明预览不可用；缓存不提供有效的路线预览凭据。
